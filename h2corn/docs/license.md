h2corn is distributed under the **MIT license**. Release packages include
the license text in `LICENSE.md`.

## Third-party notices

`LICENSE-THIRD-PARTY.md` lists the bundled Rust dependencies and their license
notices. It is included with the license text in release packages.

Optional dependencies such as uvloop are separately licensed by their
respective projects.
