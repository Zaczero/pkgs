# Zaczero's Packages

Python libraries and native tools. Each project has its own installation and usage guide.

| Project | What it does |
| --- | --- |
| [gometry](gometry/README.md) · [docs](https://gometry.monicz.dev/) | Geometry, CRS, geodesy, grids, and spatial indexing in one Python package. |
| [h2corn](h2corn/README.md) · [docs](https://h2corn.monicz.dev/) | HTTP/2 ASGI server for Python, written in Rust. |
| [blurhash-rs](blurhash-rs/README.md) | Encode and decode BlurHash image placeholders. |
| [fast](fast/README.md) | Compare Linux commands with timing and resource measurements. |
| [githead](githead/README.md) | Read Git HEAD without launching Git. |
| [httpx-secure](httpx-secure/README.md) | Destination-address protection for HTTPX. |
| [jinja2-htmlmin](jinja2-htmlmin/README.md) | Minify HTML templates before Jinja compiles them. |
| [lrucache-rs](lrucache-rs/README.md) | A bounded least-recently-used cache for Python. |
| [osm-shortlink](osm-shortlink/README.md) | Encode and decode OpenStreetMap shortlinks. |
| [polyline-rs](polyline-rs/README.md) | Encode and decode Google polylines. |
| [pyo3stubs](pyo3stubs/README.md) | Keep PyO3 typing stubs, runtime APIs, and docstrings in sync. |
| [sizestr](sizestr/README.md) | Human-readable byte counts. |
| [starlette-compress](starlette-compress/README.md) | Zstandard, Brotli, and Gzip compression for ASGI responses. |
| [totp-rs](totp-rs/README.md) | Generate and verify time-based one-time passwords. |
| [zid](zid/README.md) | Sortable 64-bit integer identifiers. |
