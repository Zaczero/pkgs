# Zaczero's Packages

This repository contains 15 projects: Python distributions and the `fast` Linux command-line tool. Each row names the distribution, import or command, purpose, and installation route. Use the linked README for project guidance; gometry and h2corn also publish dedicated documentation sites. Report a bug or request a feature in the [repository issue tracker](https://github.com/Zaczero/pkgs/issues), and name the affected project.
